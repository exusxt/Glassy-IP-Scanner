Glassy IP Scanner

A modern, fast and lightweight network discovery tool with a glassmorphic interface.

Windows · macOS · Linux Local-first · no account Open source · MIT IPv4 discovery · ICMP / ARP / TCP
⬇ Download latest release View on GitHub

What it does

🔎Fast scanning

Scan single IPs, ranges or CIDR blocks with configurable speed, pause/resume/cancel and real-time results.

🧠Device intelligence

Hostnames, MAC vendors and device-type classification — plus custom names, notes, tags and favorites.

🔌Port scanner

Built-in TCP port scanning with presets, custom ranges and service names for well-known ports.

🗺️Network map

Interactive topology with the gateway at the center, SNMP switch detection, zoom/pan and image export.

🔔Monitoring

A persistent known-device ledger raises new-device, back-online and went-offline alerts between scans.

📜Scan history

Every scan is recorded; compare any two to see exactly what changed on your network.

💾Backup & restore

Export all local data (settings, profiles, map, ledger, history) to a single JSON file and move between machines.

🔒Privacy first

No account, no cloud, no telemetry. All scanning and data storage happens on your machine.
